# GENRE PROFILE: SHORT DRAMA

## Overview
Short narrative drama focusing on emotional engagement, character consistency, dialogue, and cinematic cutting.

## Structure
1. **Scene Setup (5-10s)**: Establish setting, character position, and initial emotional tension.
2. **Action / Exchange (5-10s)**: Character action, line delivery, reaction shot.
3. **Climax / Twist (5-10s)**: Turning point, emotional expression, dramatic reveal.
4. **Resolution (5s)**: Aftermath, lingering mood.

## Key Rules
- **Character Consistency First**: Generate a character reference sheet first. Inject the identical character reference image across every shot.
- **Dialogue & Audio**: Use clear dialogue soundscape; verify dialogue fidelity with STT where applicable.
- **Shot-to-Shot Continuity**: Check the last frame of the previous clip against the first frame of the new clip. Maintain lighting direction and clothing consistency.
- **Review Weights**: Continuity (2x weight), Facial naturalness (instant fail on severe distortion).
